\subsection{Objetivos}

\subsubsection{General}
Implementar y verificar el enrutamiento Inter-VLAN en entornos simulados mediante tres técnicas diferentes: Inter-VLAN Routing heredado, Router-on-a-Stick y switch de capa 3 con interfaces virtuales (SVIs), comprobando la conectividad entre dispositivos pertenecientes a distintas VLAN.

\subsubsection{Específicos}
\begin{itemize}
    \item Configurar VLAN, puertos de acceso y enlaces troncales en switches para segmentar correctamente la red.
    \item Implementar el enrutamiento entre VLAN mediante router con interfaces físicas, router con subinterfaces y switch multicapa.
    \item Validar la comunicación entre redes a través de pruebas de conectividad utilizando el comando \texttt{ping}.
\end{itemize}

\subsubsection{Ejercicio 1: Inter-VLAN Routing heredado}

En el primer ejercicio se implementó el enrutamiento Inter-VLAN heredado, técnica en la que un router utiliza interfaces físicas independientes para permitir la comunicación entre diferentes VLAN. En este esquema, cada interfaz del router actúa como puerta de enlace predeterminada para una red distinta, lo que permite que el tráfico sea enviado desde una VLAN hacia otra a través de un dispositivo de capa 3 externo.

Posteriormente, se configuraron las interfaces físicas del router con las direcciones IP 207.150.75.1 y 207.150.150.1, correspondientes a las redes 207.150.75.0/24 y 207.150.150.0/24.

\paragraph{Comandos de configuración y verificación utilizados}

\begin{verbatim}
enable
configure terminal
vlan 10
name VLAN10

\subsubsection{Ejercicio 2: Router-on-a-Stick}

En el segundo ejercicio se implementó la técnica Router-on-a-Stick, en la cual un único enlace físico entre el switch y el router transporta el tráfico de múltiples VLAN mediante subinterfaces configuradas con encapsulación IEEE 802.1Q. Esta solución permitió reducir el uso de interfaces físicas del router y mejorar la escalabilidad de la red frente al método heredado.

En este escenario se trabajó con tres VLAN activas: VLAN 10 asociada a la red 207.150.75.0/24, VLAN 20 asociada a la red 207.150.150.0/24 y VLAN 30 asociada a la red 208.160.80.0/24. Cada una de estas redes tuvo como puerta de enlace una subinterfaz del router configurada con encapsulación \texttt{dot1Q}.

\paragraph{Comandos de configuración y verificación utilizados}
Para la implementación de Router-on-a-Stick se configuraron VLAN en los switches, enlaces troncales y subinterfaces en el router con encapsulación IEEE 802.1Q, permitiendo el transporte de múltiples VLAN a través de un solo enlace físico.

\textbf{Comandos principales en switches:}
\begin{verbatim}
enable
configure terminal
vlan 10
name vlan10
exit
vlan 20
name vlan20
exit
vlan 30
name vlan30
exit

interface range f0/10-15
switchport mode access
switchport access vlan 10
exit

interface range f0/16-20
switchport mode access
switchport access vlan 20
exit

interface range f0/3-7
switchport mode access
switchport access vlan 30
exit

interface f0/1
switchport mode trunk
exit

interface f0/2
switchport mode trunk
exit
\end{verbatim}

\textbf{Comandos principales en el router:}
\begin{verbatim}
enable
configure terminal
interface g0/0
no shutdown
exit

interface g0/0.10
encapsulation dot1Q 10
ip address 207.150.75.1 255.255.255.0
exit

interface g0/0.20
encapsulation dot1Q 20
ip address 207.150.150.1 255.255.255.0
exit

interface g0/0.30
encapsulation dot1Q 30
ip address 208.160.80.1 255.255.255.0
exit
\end{verbatim}

\textbf{Comandos de verificación:}
\begin{verbatim}
show vlan brief
show interfaces trunk
show running-config
\end{verbatim}

\textbf{Pruebas de conectividad:}
\begin{verbatim}
ping 207.150.75.2
ping 207.150.150.2
ping 208.160.80.2
\end{verbatim}

El switch multicapa fue configurado con las interfaces \texttt{Vlan10} y \texttt{Vlan20}, asignándoles las direcciones IP 207.150.75.1 y 207.150.150.1, que funcionaron como puertas de enlace para los hosts de cada segmento.

\subsection{Conclusiones}
La práctica permitió comprender de manera aplicada tres métodos distintos de enrutamiento Inter-VLAN. El método heredado demostró el principio básico de comunicación entre VLAN a través de interfaces físicas de router, pero evidenció limitaciones de escalabilidad. Por su parte, Router-on-a-Stick permitió optimizar recursos al utilizar subinterfaces sobre un único enlace físico troncal, mientras que el switch de capa 3 con SVIs ofreció una solución más integrada, eficiente y adecuada para entornos con mayor demanda de segmentación y rendimiento.

Adicionalmente, la guía fortaleció competencias relacionadas con la segmentación lógica de redes, la configuración de gateways, la administración de puertos de acceso, el uso de enlaces troncales y la verificación del flujo de paquetes entre diferentes dominios de broadcast.

\begin{itemize}
    \item Verificar cuidadosamente la coherencia entre VLAN, direccionamiento IP, máscara de subred y puerta de enlace antes de realizar pruebas de conectividad.
    \item Confirmar que los puertos troncales permitan el paso de todas las VLAN requeridas y que los puertos de acceso estén asignados al segmento correcto.
    \item Documentar mediante capturas las configuraciones y pruebas realizadas, a fin de respaldar los resultados obtenidos en la práctica.

\end{itemize}
